## 0. 预审口径（先读）

1. **对比度公式**（WCAG 2.1 相对亮度法）：`CR = (L1 + 0.05) / (L2 + 0.05)`（L1 为较亮色），其中 `L = 0.2126·R′ + 0.7152·G′ + 0.0722·B′`，通道线性化为 `c ≤ 0.03928 → c/12.92`，否则 `((c + 0.055)/1.055)^2.4`。阈值：正文 4.5:1；大字（≥18pt 或 ≥14pt bold）与非文本指示器/图形 3:1。
2. **豁免纪律**：浅色涨跌语义色为显式登记豁免（global.css 注释「显式豁免 4.5 口径，见设计规范 5.3」）；本预审不新增豁免，全部提案色按上表阈值验算。
3. **浅色底参考**：提案画布 Paper `#F6F8F7` 与现画布 `--wf-bg-sunken #F8F7F3`（global.css:59）亮度极接近（同为近白）；§1.2 主表浅色组合按 Paper 与卡底 `#FFFFFF`（`--wf-bg-surface`，global.css:61）双底给出。深色底按提案画布 Ink Navy `#102331`（现深画布为 `#17171A`，global.css:323 深色块内）。**既有底增量口径（评审复核轮补）**：准入逐键进行，新色先行落地时既有背景令牌仍在服役——§1.2 另设「新色 × 既有背景矩阵」按浅色既有四底（sunken/inset/surface/tint 合成）与深色既有三表面＋材质合成底逐对验算，跌破组合以用途约束回写五要素表。
4. **验算工具**：本会话自跑 node 计算（公式如上，命令与输出摘录见 §6）；并跑通仓库门禁 `npm run check:a11y` → 23 组令牌对通过、违规 0 处——该脚本只覆盖**现值**，提案值须实施轮扩对复验。
5. **命名纪律**：提案令牌名在 src/ 落地前须过 check-naming（brief §八.3）；本文仅用提案色名作登记标识。

## 2. 排版令牌提案（T-1…T-6，brief §2.2）

> 现行四级字阶：display 32（≥768 40）/ title 20 / body 14 / caption 12（global.css:40-43，静态层两主题同值不入对账）。原型 §0.5 已锁定：超出四级现值的部分一律按「待 §5.1 准入的新令牌提案」处理，准入前四页 L1 读数用现值。
