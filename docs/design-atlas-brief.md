## 一、产品方向：四大任务入口（取代九面板平级目录）

核心诊断：问题不是功能多，而是**不同认知层级的内容被放在同一级交互结构**——结果/参数/解释/依据混排，
用户任务与功能名称脱节，交互停留于「输入数字→阅读结果」。

新信息架构（四个用户问题驱动的入口，替代「规划/住房/分析」三组九面板目录）：

| 新区域 | 用户问题 | 整合原有能力 | 新增体验 |
| --- | --- | --- | --- |
| **自由刻度** | 我需要多少钱？ | 基础公式、反向估算、敏感性分析 | 实时交互计算与假设对照 |
| **人生轨迹** | 我何时有机会退休？ | 打工积累、养老金、贷款、收租、税务 | 统一生命周期现金流与人生里程碑 |
| **风险实验室** | 我的计划承受得住变化吗？ | 蒙特卡洛、支取策略、情景对比、洞察 | 风险测试、策略比较、购买力与资产路径 |
| **原理档案** | 为什么这样计算？ | 公式推导（InsightsPanel）、研究引用、参数来源 | 交互式公式与可追溯证据 |

**硬约束（发布阻断级）**：
- 原有九个高级功能全部有可访问的新入口；「专业模式」直达原工具，保证既有高级用户效率；
- 分享链接/情景库/预设的兼容（share v4+ 迁移、resetEpoch 回落机制延续）；
- S1–S26 签名元素随组件迁移、零回退；方案 B 导航（分段+组内标签）由 Atlas IA **用户裁决升级取代**，
  迁移对照表 + 深链接兼容处理为 WF-03 交付物；
- 四级信息结构（Level 1 结果 / Level 2 操作 / Level 3 分析 / Level 4 依据）作为每区域的披露纪律。

## 二、Capital Atlas DS：设计令牌演进提案（须经宪法 §5.1 准入）

### 2.1 色彩提案（探索性自有令牌，非官方色值；准入前逐对验证对比度）

| 令牌 | 提案值 | 语义 |
| --- | --- | --- |
| Ink Navy | `#102331` | 主信息与深色表面 |
| Paper | `#F6F8F7` | 浅色背景 |
| Signal Teal | `#087F78` | 交互与核心数据 |
| Copper | `#A56C32` | 假设与提醒 |
| Slate | `#8195A3` | 辅助数据 |
| Soft Mint | `#DCEEE8` | 区间与轻量高亮 |

色彩纪律：大面积背景低饱和；强调色只表达操作焦点与相关数据；风险用**文字+形状+线型**多维表达
（禁纯红绿）；深浅主题独立表面/文字令牌（禁简单反色）；光学材质仅限浮动工具条/检视器/过渡层，
**密集数字的表格与图表恒用稳定不透明底**。

### 2.2 排版与空间

数字主标题 40–56px（移动 32–40）、页面标题 28–36、区域标题 20–24、正文 15–16（行高 1.6）、
元信息 12–14（对比度严格验证）；数字一律 tabular-nums、金额与单位分层；
间距 4/8/12/16/24/32/48；卡片圆角 12–20px 分级；主阅读宽 640–760px（工作台可更宽）；
图表优先保证标签与数据清晰而非固定高度。

### 2.3 三层表面材质

- **Surface 0 Canvas**：稳定纸面底——阅读/图表/表单主体；
- **Surface 1 Instrument**：细边缘低对比阴影的仪表工作区——数字编辑/分析/对照；
- **Surface 2 Optical Overlay**：仅浮动控制、局部透镜、时间节点检视器——浅色扩散+局部高光+有限透明。

巧思来源纪律：来自**视觉信息与操作行为的关联**（如时间透镜），不来自装饰性材质堆叠。

### 2.4 动效三类令牌

即时反馈 100–160ms（按钮/选中/焦点）；结构变化 200–300ms（展开/切换检视）；数据过渡 200–350ms
（数字/图表路径/区间）。数值变化用短暂数字过渡、图表强调路径连续、人生事件强调**因果关系**
（如添加孩子→生命周期图指出哪些年份支出变化，而非总数跳变）。prefers-reduced-motion 全覆盖；
低性能设备自动降载。与既有动效令牌体系（global.css）合并演进，不另起炉灶。

## 三、五个交互巧思（优先级序）

| 优先 | 交互 | 体验 | 价值 |
| --- | --- | --- | --- |
| 1 | **时间透镜 Time Lens** | 拖动年龄刻度，同步检视该年龄的收入/支出/资产/购买力 | 把抽象曲线变成可探索的人生 |
| 2 | **公式解构 Formula Anatomy** | 点击公式变量→高亮对应参数及其对结果的影响 | 代替大段公式说明 |
| 3 | **情景叠影 Scenario Overlay** | 基准与调整后资产路径同图叠加、突出差异 | 消除来回切换的记忆成本 |
| 4 | **假设溯源 Assumption Lens** | 点击默认值→查看来源/年份/口径/局限 | 模型透明度 |
| 5 | **人生事件胶囊 Life Events** | 时间轴加入购房/育儿/失业/退休事件 | 比一次性填十几个字段直观 |

反采纳（明确不做）：3D 地球、粒子系统、复杂关系网络、持续漂浮图形——视觉新奇但认知效率下降；
界面同时出现的选项数量下降**不以牺牲实际能力为代价**（NN/g 复杂应用原则）。

## 四、响应式与人体工程学规格

| 容器宽度 | 布局 |
| --- | --- |
| 320–479 | 单列、底部主操作、底部参数面板 |
| 480–767 | 单列增强，局部双栏简表 |
| 768–1023 | 主内容 + 按需侧栏或浮动检视器 |
| 1024–1439 | 双栏工作台，主图优先 |
| 1440+ | 更宽工作区，但限制文本阅读宽度 |

- 断点优先 **CSS Container Queries**（按组件容器宽度，非仅视口）；渐进启用，不破坏既有断点纪律；
- 触控目标：主要交互以 **44×44 CSS px** 为工程目标（高于 WCAG 2.2 AA 的 24px 合规线）；
- 高频操作靠近移动端底部易触达区；关键操作不依赖悬停；输入框用数字键盘、允许精确输入；
- 图表同时支持触控/点击/键盘与可访问数据表格；横向滚动仅限图表内部；
- Sheet 打开时正确管理焦点/背景滚动/虚拟键盘/安全区；200%–400% 缩放无关键内容裁切；
- 参数变化后焦点不得被不必要重置。

## 七、发布阻断条件（采纳为各 WF 的验收门）

| 维度 | 条件 |
| --- | --- |
| 完整功能 | 九个高级功能全部有可访问新入口 |
| 计算正确性 | 关键财务模型与独立参考算例一致 |

## 八、与既有资产的衔接裁定

1. **组件库**：不新增运行时依赖——TDesign/Semi/**Ant Design** 是设计参照与组件行为对照（如 Semi
   Collapse 卸载 DOM 的 keepDOM 教训 → 对应本仓 Tabs hidden 非卸载模式，已符合），迁移仅在 ADR
   论证收益后渐进。**Ant Design 研究靶点（WF-02 交付物输入，用户 2026-11 指定纳入）**：
   - antd v5 令牌系统与算法化深色主题（theme algorithm 派生 vs 本仓 CSS 变量三源对账——令牌架构对照）；
   - ProComponents 工作台模式（ProCard 分栏 / StatisticCard 指标卡 / ProForm 分步表单）——对应
     「自由刻度」首屏、双栏工作台与人生规划分步引导；
   - Form 联动校验模式（dependencies / 动态规则）——对照基础参数联动与联动目标值口径；
   - antd-mobile 的单任务移动结构（对应 §四 移动布局：底部主操作 + 参数面板）；
   - antd Statistic / Table 数值排版惯例（tabular-nums、汇总行）——对照既有 S 项数字纪律。
2. **宪法衔接**：Atlas IA 与 DS 令牌演进全部走 design-language §5.1（三步制）与 §5.3（原则修订需
   体系级证据）；北极星「静水账房」人格延续——Atlas 是「图谱化信息架构」愿景，不是视觉推翻。
3. **命名纪律**：设计术语含品牌禁词子串的（如某光学材质机制名）在 src/ 内一律用自然描述替代。
4. **P7 并行纪律**：P7（财务决策语义修正）运行期间不启动 WF 系列；WF-01 在 P7 验收部署后启动。
