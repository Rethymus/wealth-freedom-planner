## 0. 北极星

**定案：候选一「静水账房」为主体，吸收候选二「读数行」与候选三「环刻度」两个可零成本落地的部件。**

一句话概念：**把界面做成一间安静而精密的私人账房——每个数字都被认真对待，庆祝只发生一次，且小到几乎只剩一次呼吸。**

- **视觉隐喻**：刻度尺 + 发丝线分组 + 读数窗。进度环 = 量具刻度（四档刻度点），大数字 = 读数窗（等宽字排、永不抖动），分组标线 = 账房的栏线（发丝线承载层级，不靠阴影堆砌）。
- **语气关键词**：安静、精密、诚实、从容。
- **定案理由**（证据见 research-design-language.md §0）：
  1. 与既有三层材质 / 发丝线 / 三档时长两族曲线令牌体系零架构冲突，属延续性升级（global.css:147-285 既有材质区原样保留）；
  2. 语气与体系 B「built for focus」、体系 A「Keep restraint」双口径互证；
  3. 巧思目录 14 项中半数为纯 CSS 实现，尺寸门禁压力最小（本仓门禁为原始字节硬限，见 p5-spec §10）。
- **落选说明**：候选二全部并入（行级 hover 读数、诚实进度尺、方向冗余编码均采纳）；候选三「时间的朋友」因需 WASM 输出契约新增时间轴字段（数据流改动，违反巧思边界）整体落选，仅吸收其「环刻度」思想并把刻度改为百分比档（25/50/75/100，零数据层改动）。
- **冷感风险的对冲**：账房感偏冷，由空态人格化（签名元素 S6）与文案温度补偿（p5-spec §5 空态「一句话 + 动作」口径）承担。

## 1. 设计原则（五条，每条一句话）

1. **数字是主角，界面是账房**：一切装饰、动效、文案不得遮蔽读数；会变化的数字一律等宽字排，永不因排印抖动。
2. **克制庆祝**：全站唯一的庆祝动效留给「达成 100%」时刻——单次、不循环、300ms 级；绝不撒花、绝不数字游行（体系 A《Certain》Keep restraint；行业文章 P 口径）。
3. **反冗长**：解释性正文 ≤2 行，口径与出处归 tooltip，文字墙清零——这是唯一可测的「可感下降」指标（research-fintech-ui.md §6）。
4. **状态诚实**：进度显示真实百分比、计算窗口明示「算着呢」、降级明示原因，不假进度、不静默等待（行业文章 P「honest feedback」口径）。
5. **双主题同格**：每个新视觉元素亮深两套值同轮验收，深色层级靠「越高越亮」的表面明度差 + 阴影加重（体系 C《Elevation》深色口径；global.css:293-337 既有纪律）。

## 3. 组件规范（应用规则；参数对照表 = research-design-language.md §3）

### 3.1 字阶（四级定案）

| 令牌 | 值 | 用途 | 应用规则 |
| --- | --- | --- | --- |
| `--wf-text-display` | 32px / ≥768 40px | 全站唯一读数窗（输出卡临界值） | 每屏至多一处（desktop 双栏下左栏 hero 是唯一 40px）；等宽字排 + bold；右栏面板大数禁用本档 |
| `--wf-text-title` | 20px | 面板级主数（右栏模拟结果）与大节标题 | bold；与 display 保持 1:2 从属比 |
| `--wf-text-body` | 14px | 正文、字段标签、Descriptions 值 | 默认档；金额 ≥13px 下限由 body 达标 |
| `--wf-text-caption` | 12px | 口径注、图表刻度、hint、图例 | 说明性文字；正文内连续说明 ≤2 行（反冗长原则） |

对照依据：体系 C《Typography》metric.large 28/32 bold、body 14/20、body.small 12/16 与体系 B web ramp（研究 §3.1）；13px 旧档并入 body（顶栏标签 +1px 的视觉变更登记 p5-spec deviations）。**禁止 letter-spacing 作用于数字**（research-fintech-ui.md §1）。

### 3.2 表面（分层背景 + 三层材质）

- 实底三档 + 材质浮层：`--wf-bg-sunken`（页面画布）→ `--wf-bg-inset`（面板凹面区）→ `--wf-bg-surface`（平面卡底）；浮层**不设实底令牌**，由半透明材质层承担（`--wf-surface-overlay-*` → .arco-select-popup / .arco-tooltip-content）。深色按「越高越亮」排布（体系 C《Elevation》深色口径）。（P5.1 修订：原第四档 `--wf-bg-overlay` 全仓零定义零消费，属幽灵键引用，经 §5.1 走修订记录清除。）
- 半透明三层材质（顶栏 / 悬浮输出卡 / 浮层，global.css:147-285）**原样保留**，是本设计语言的既有骨架；普通内容卡片一律实底走四档背景令牌。
- hover / pressed 用**表面色变化**（`--wf-bg-tint` 半档），不用海拔动画；「hover 升档到浮层海拔」全站禁止（体系 C 交互口径）。

### 3.3 间距（8pt 刻度，现状保持）

`--wf-space-1..7`（4/8/12/16/24/32/48px）。小档 0–8px 用于图标-文字间隙与密集表单；中档 12–24px 用于卡片纵向节奏；大档 32–48px 用于区块间距。组间 ≥24px（--wf-space-5，global.css:1147-1153 D10 既有口径）为硬规则。

### 3.4 圆角（三档一全，现状保持）

`--wf-radius-s/m/l`（6/10/14px）落在体系 C《Radius》medium–large–xlarge 同一斜率上（研究 §3.5）；`--wf-radius-full` 用于圆件。焦点环 = 组件圆角 +2px、外偏 2px 的既有双环实现（design-spec 2.8），不动。

### 3.5 动效（三档三族，现状保持 + 两处显式派生）

- 时长三档：快 120ms（交互反馈）/ 基 240ms（进出场）/ 慢 360ms（大面积）；曲线三族：标准 / 强调 / 渐近（global.css:92-98）。
- **循环动效派生口径**：S9 呼吸的循环周期 = `calc(var(--wf-dur-slow) * 2)`，单一事实来源仍是慢档令牌，不新增时长键；循环类动效仅允许出现在「状态窗口期」（计算中）且落定即停。
- **单次脉冲口径**：S2 用强调曲线 + `animation-iteration-count: 1`；体系 C《Motion》「一场景一次的重要时刻才允许更长更表达」是唯一豁免依据（研究 §3.4）。
- 退场一律比进入快；透明度只走标准曲线，强调曲线只作用于位移与缩放（global.css:549-576 既有条款延续）。
- prefers-reduced-motion 命中 = 动效关闭且瞬时（CSS 兜底块 + JS hook 双闸，缺一不可）。

### 3.6 图表质感（research-fintech-ui.md §3 收编为规范）

仅水平 1px 实线网格挂图表网格令牌；轴去框去刻度短线，刻度文字 12px 等宽字排；语义色只在「比较语境」出现且每图一个维度；叙事标注（S15）只准引用已算出的结果字段。
