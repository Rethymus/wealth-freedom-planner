## ① 业界主流设计规范要点汇总

### 1.1 龙卷风图（敏感性分析图形化）

龙卷风图（tornado diagram）源自决策分析领域，用于展示**单变量敏感性分析**（one-way sensitivity）结果：逐一改变一个输入变量、其余变量固定在基准值，观察输出指标的变化幅度（业界决策分析实践指南原文口径）。

| 维度 | 主流规范 |
| --- | --- |
| **布局** | 水平条形图，类别轴纵排；每个变量一条横条，条带**从基准值向偏离侧伸展**；图中有一条**中央垂直参考线 = 基准情形输出值**（多来源一致口径：「垂直线表示基准情形结果」）。柱体不设共同基线，靠参考线对齐 |
| **排序** | 按**影响宽度（偏离幅度）从大到小降序排列，最大者在顶**，次大者紧随，形成「龙卷风」形态（决策分析指南与百科条目一致口径） |
| **颜色语义** | 每条分**基准两侧两段/两色**（低值侧 vs 高值侧），辅以图例；历史上也通行灰度单色系。红绿对是**明确反例**——公开色彩通用设计口径：红绿色觉障碍在男性中比例约 4–8%，主流图表库指南已把「蓝增/橙减」定为色盲安全默认对 |
| **标签** | 变量名置于类别轴；条带两端标注输出值；必要时以虚线叠加目标线/预算线（案例口径：超出预算线即一眼可判） |
| **能力边界（须随图声明）** | 只反映单变量敏感性，**不含变量间交互效应**；条带宽度完全取决于所选低/高档位是否现实——档位须有业务依据（业界指南列为其两条主要局限） |

对本项目的映射：现有敏感性小节是**单变量（月开销）× 六档**（±10/±20/±30%），不是多变量龙卷风。适配口径：每档 = 一条横柱，柱从基准临界值向该档临界值伸展（宽度 = |档位临界值 − 基准临界值|），按宽度降序排列形成「偏离龙卷风」；颜色语义从「低/高输入侧」平移为「输出方向」——临界值高于基准（更难达成）用跌系色、低于基准（更易达成）用涨系色。此映射如实登记为单变量特化形态，与经典多变量龙卷风的差异见 §2.2 B1 注。

### 1.2 瀑布图（现金流桥接）

瀑布图（waterfall chart）源自管理咨询与公司财务（又称 bridge chart），用于展示**一个起始值经一系列带符号变动到达终点值**的过程（业界图表库完整指南口径）。

| 维度 | 主流规范 |
| --- | --- |
| **结构** | 起点/终点/小计柱**从零起**（可从轴直接读数）；变动柱**悬浮**（起于前柱终点、止于新的累计位）；**虚线连接线**连接前柱终点与后柱起点，引导视线沿累计值左右移动 |
| **配色三角色** | 起始/终点/小计柱 = **中性色**（深灰或主色系，指南推荐口径）；增加柱与减少柱各一色。金融惯例为绿增红减，但该组合对红绿色觉障碍不可分；主流指南把**蓝增/橙减**定为可读性更好的推荐默认，并给出备选方案「变动柱灰、合计柱彩色」（层级优先时）与「单柱高亮」（突出单一变动时） |
| **连接线** | 细、浅色（叙事式图表指南原文：「保持连接线细且浅，不与数据竞争视觉」）；可开关，推荐保留——它明示「下一柱的起点 = 上一柱的终点」 |
| **标签** | **每个变动柱标注带符号的变动值，每个合计柱标注累计值**（指南清单原文口径）；标签直标优于远距图例匹配；或保留 y 轴供读数（无一致基线时人眼对悬浮柱高度比较不准——指南明确提示）；标签防重叠由布局保证 |
| **数据处理** | 小计必须**标记为合计类型而非变动步骤**，否则图表重复累计且无报错（指南清单原文「Don't」第一条）；无关紧要时可按大小重排变动项并把小额项并入「其他」；变动步数上限意识（「展示 30 步没人会读」口径）；轴不必从零起时可标注说明 |
| **替代方案** | 若读者主要目标是「给多个变动排序」→ 排序条形图更准（共享基线比较优于悬浮柱，感知实验经典结论口径）；有始末含义的桥接才用瀑布图 |

对本项目的映射：收租面板年度明细即「年毛租金 → 扣减项 → 年净现金流」的桥接，是瀑布图的教科书场景。数据契约（`src/wasm/src/rental.rs:184`：`net = effective − rent_tax − maintenance − property_fee − other − annual_loan_payment`；`effective = gross − vacancy`）天然构成 **9 列瀑布**：毛租金（起）→ −空置损失 → 有效租金（**小计**）→ −租金税 → −维护 → −物业 → −其他 → −年供款 → 净现金流（终）。首付与贷款金额为一次性金额（`RentalBreakdown` 契约注释口径），不入年度现金流瀑布。

### 1.3 双主题下的图表可读性（网格线 / 文字 / 系列色两套参数）

- **明度反转原则**：业界数据可视化工具的自动深色模式算法口径——**每个图表元素对底色的对比度在两主题下保持不变**；「白底上很暗的颜色在黑底上应变得很亮，反之亦然」。即两套参数不是两套色板，而是**同一对比度目标的两份明度实现**。
- **对比度目标**：业界数据可视化色彩指南口径——前景对背景**大文本 ≥ 2.5:1、小文本 ≥ 4:1**；开放无障碍标准口径更严（文字 ≥ 4.5:1、非文本指示 ≥ 3:1），本仓验收一律从严取标准口径（design-spec 5.3 唯一口径维持）。
- **网格线**：深色下网格线「变成更深的灰」，以可感知为限、不与数据竞争（业界深色图表实践共识口径）；网格属装饰层，不设 3:1 口径（与本仓 design-spec 8「网格线为装饰层」既定口径一致）。网格用虚线降低视觉权重（本仓 `3 3` dash 已符合）。
- **系列色**：深色下**降饱和、提亮度**（平台级设计规范深色章节口径：高饱和色在暗表面上视觉「抖动」）；系列间区分优先靠色相 + 明度双通道，并叠加冗余编码（1.5 节）。
- **两套参数的载体形态**：同一组键名、两份值（本仓 `THEME` / `THEME_DARK` 双组令牌即此形态——`chartGrid` / `chartTick` 已双主题在位）；组件代码不感知主题、经统一解析函数取值（design-spec 8 既有口径）。

### 1.4 空态与加载态

- **空态结构**：业界通行结构为**图标 + 描述（+ 可选行动入口）**；组件级空态组件（组件库 `Empty` 组件实测：`description` / `icon` / `imgSrc` 三参数，默认图标为内联 SVG 图标、图标与文字同用中性灰阶、描述字号 14px、整体内边距 24px、图与文间距 8px——组件库包内样式令牌实测）。空态文案与正文同级可读（即 1.3 对比度口径）。**绝不留无提示空白**（第一轮 1.7 口径维持）。
- **加载阈值**（业界可用性研究通行响应时间界限）：**0.1s** 内系统显得即时；**1s** 内不打断思路（可察觉但无需指示器）；**10s** 是注意力上限（超过须给进度反馈）。**2–9s 的等待用旋转指示器、10s 以上用进度指示器**。**指示器延迟显示**：等待极短（约 < 300–500ms）时指示器一闪而过反而有害，业界通行做法是延迟显示（组件库 `Spin` 组件原生支持 `delay` 参数，单位 ms——组件库接口实测）。
- **触发式动作**：按钮内嵌 loading 态 + 禁用防重复提交（第一轮 1.7 口径维持，本仓已落地）。
- **计算面板适配**：毫秒级计算不出加载态（防抖即时输出）；数百毫秒至数秒的计算用「旋转器 + 文字说明」；骨架屏不适用（第一轮 N5 结论维持）。

### 1.5 图表可访问性（色盲安全与数据表替代）

- **颜色不得是唯一视觉手段**（WCAG 2.2「1.4.1 颜色使用」Level A 原文口径：颜色不作为传达信息、指示动作、提示响应或区分元素的唯一视觉手段）。官方给出的充分技术：**G111（颜色与图案并用）**、**G14（颜色传达的信息同时以文本提供）**；典型失败案例 F13 即「图表仅以颜色传达信息」。另注：两色若明度差 ≥ 3:1 也可算附加区分，但「需要精确辨认某特定颜色」的场景仍须额外指示——即明度差不豁免冗余编码义务。
- **数据表替代**（WCAG 官方教程「复杂图像」章原文口径）：图表这类复杂图像应有**短描述（图 alt/aria 标签）+ 长描述**；结构化长描述推荐以**相邻的可见数据表**承载（`figure` + `figcaption` 结构关联，或图旁直接放表）；**`aria-describedby` 只适合纯文本长描述**——读屏对其内表格等结构不保留导航能力，官方明示该局限，故结构化数据一律用可见表而非 `aria-describedby`。
- **色盲安全**：公开无歧义色板（蓝 `#0072B2`、橙 `#E69F00`、天蓝 `#56B4E9` 等）为业界通行替代板；蓝/橙对是涨/跌双分类最常用替代（第一轮 1.8 口径维持）。**直接标注优于远距图例匹配**（色彩通用设计原文建议）；图表图形加 `role="img"` + `aria-label` 汇总句（本仓自由刻度进度环已有先例，`BasicCalculator.tsx:146-147`）。

## ③ 明确不采纳项及理由

| # | 业界做法 | 不采纳理由 |
| --- | --- | --- |
| N11 | 多变量龙卷风图（收入/回报率/通胀/月开销各一档两色条） | 数据层现状只产出单变量六档（`SENS_STEPS`）；多变量需核心新增逐变量扫描接口，超出本轮范围（登记为后续数据层扩展项）；单变量六档的「偏离龙卷风」形态已获得排序 + 基准线 + 方向色三通道收益 |
| N12 | 灰度单色龙卷风（决策分析纸面时代惯例） | 失去方向语义通道；双色 + 色盲友好开关已覆盖同类信息且深色组全部达标 |
