## §0 术语与判据（先读）

- **零滚动**：任一任务页任一「叶」在参考视口（320×720、1440×900）内同时可见的全部节点高度加总 ≤ 内容栈预算；
  内容区禁止滚动兜底（含页内 `overflow-y:auto` 内滚），超预算一律走**切换消化**（brief §七「无关键内容裁切」+ 本纪律双重约束）。
- **切换树**：根（页）→ 切换节点（tab / 步骤 / 分段 / 条目）→ 叶或槽。
- **槽（slot）**：高度恒定的区域，内部内容切换时**等高互换**（替换不加高）——这是与现状加性 Collapse 的本质差异；
  折叠节点按**闭合态**计预算，展开内容只能占据既有的某个槽。
- 叶内**固定分区**（如读数窗）不是切换节点，但参与预算加总，逐行入表。
- **验收判据（p10-spec 落地为新门禁）**：每任务页每叶 × 两参考视口，DOM 断言 `scrollHeight ≤ clientHeight`
  且页根 `getComputedStyle().overflowY === "visible|hidden"` 非 `auto/scroll`；本文 §1 各加总表即该门禁的静态预算底稿。

## §2 骨架设计：100dvh 锁定 + flex 分工 + sticky 退役/迁移登记

### §2.1 骨架

```text
<Layout style={{ height: "100vh" }} → 覆写 height:"100dvh"   /* 替换现 minHeight:"100vh" App.tsx:395 */
  Header  flex:none; height:56      /* position:sticky 退役（§2-T1）：无滚动即无吸附语义 */
  SwitchBar flex:none; height 48/56 /* 恒驻；desc<768 转 title/aria（信息不丢） */
  Content  flex:1; min-height:0; padding 8/16; overflow:hidden
    └ .atlas-page(×5) height:100%; overflow:hidden; display:flex; column
  （Footer 元素退役 → 声明迁移 E5，§2-T11）
```

- `min-height:0` 是关键：使 flex 子区可被真实测高，页内槽预算才成立；dvh 防移动端地址栏伸缩导致 720 基准失真
  （回退顺序 `height:100vh` → `height:100dvh`，`@supports` 不需要——dvh 直接覆写，旧浏览器忽略即得 vh 值）。
- 任务切换反馈（App.tsx:188-196）：`scrollIntoView` 滚动复位退役（无滚动可复位），保留 `focus({preventScroll:true})` 焦点迁移——信息路径（切换后焦点落新页根）先迁移后删滚动（App.tsx:194）。
- 迁移提示 Alert（App.tsx:516-524）：一次性说明改 Message 气泡（覆盖层，零布局高度）；换算提示 Alert（App.tsx:495-508）：改顶栏币种 Select 旁 info 触发器，tooltip 承载汇率+时点全文（非 CNY 才渲染）。
