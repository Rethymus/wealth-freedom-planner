## §3 过期判据设计（每项归入 L1–L5 一类）

| 类别 | 判据 | soft 级 | hard 级 | 覆盖项 |
| --- | --- | --- | --- | --- |
| L1 官方年度统计 | 存在更新的年度官方发布而未采值 | 发布窗口已过未更新（如 NBS 年度收支＞14 个月、工资＞18 个月、年金＞15 个月未复核） | 连续两届未采值 | D1, I3, I4, I5, I8, I11, I12, I17, PE2, R1–R8 |
| L2 法规/税表 | 表内 `year` 字段 < 当前适用年度 | 落后一届（如 2025 表对 2026 税年）→ 提示「内置 {year} 年度税表，当前年度可能已更新」 | 落后两届及以上 | T1–T9, PE1（制度表：修法即 hard） |
| L3 市场滚动 | CHECKED_AT 距今 | >6 个月；年度序列类=「上年收宫后未在 Q1 补录年度值」（X1 现状即命中） | >12 个月 | C1–C16, X1, X2, D15（快照类豁免 hard，机制内滚动） |

**UI 提示口径**（三档，落点=「数据依据」折叠头角标＋设置页数据时效清单）：

- ok：不展示任何标记（诚实性纪律：无缺口不占视觉资源）。
- soft：角标「数据为 {YEAR} 年度口径」；详情句模板：`本值基于 {YEAR} 年度官方数据，最新年度发布窗口为 {NEXT_DUE}，复核于 {CHECKED_AT}。`
- hard：角标「该数据已落后官方最新发布」；详情句模板：`官方已于 {NEW_DATE} 发布 {NEW_VALUE}，当前展示值为 {OLD_VALUE}（{YEAR} 年度）。`
- 禁则沿用 data-dictionary §4：不写「研究表明/历史平均」（假设区间）、不把折月值写成官方月度数据、社保收益率仅按句式 3/5 与年份边界同源引用、待证项展示「复核受限」而非编造更新值。

## §4 数据文件头部元数据 schema（YEAR/CHECKED_AT/SOURCE 注释块）

**单源文件模板**（整文件同源：pensionParams/indexSeries/rentParams/regional 类）：

```ts
/**
 * @data-meta
 *   YEAR: 2025               // 统计年份；快照/序列类=数据时点（如 2026-11）
 *   CHECKED_AT: 2026-11-24   // 最近复核日（官方直读或权威转述核对当日，ISO 8601）
 *   NEXT_DUE: 2027-05        // 下一官方发布窗口（YYYY-MM；无固定周期可省略）
 *   SOURCE_TYPE: official    // official | media | video | engineering | derived | snapshot | rolling
 *   EXPIRY: L1               // 过期判据类别 L1–L5（见 research-p11-data-audit §3）
 *   SOURCE:
 *     - 国家统计局《2025年城镇单位就业人员年平均工资情况》，stats.gov.cn，2026-05-15
 */
```

**逐条目内联形式**（异源多表文件：taxTables/insights/presets）：条目对象上方单行注释
`// @data-meta YEAR=2026 CHECKED_AT=2026-11-24 SOURCE_TYPE=media EXPIRY=L2`

**字段语义与机读规则**：

1. `YEAR`：与税表结构化 `year` 字段同源（L2 类二者必须一致，check:data 断言）；展示类=统计年份；派生类=省略（继承基座）。
2. `CHECKED_AT`：复核动作发生的日期，不是数据发布日；每次改值或复核必须刷新（与 data-dictionary「复核」列同一纪律：改动行必须刷新）。
3. `NEXT_DUE`：仅 L1/L3 必填；取值锚=各官方发布节奏（NBS 年度收支 2027-01、工资 2027-05、年金摘要 2027-03、社保基金年报 2027-09、世行 WDI 2027-07、Slickcharts 年度收宫后 Q1、Numbeo 每半年）。
4. `SOURCE_TYPE`/`EXPIRY`：与 insights 核证三级＋§3 判据类别一一对应；`derived` 禁填 SOURCE（须引用基座 ID）。

**机读落地建议**（零新依赖，先例 check-data.mjs 的 esbuild 转译管线）：新增组 J 断言——①每数据文件头存在 `@data-meta` 块且必填键齐备；②`CHECKED_AT` 为合法 ISO 日期且 ≤ 构建日；③L1/L2/L3 类 `CHECKED_AT` 未超 §3 soft 阈值（CI 时点对 L2 额外断言税表 `year` ≥ 当前适用年度−1）；④`NEXT_DUE` 已过窗口且未刷新时输出提醒（非阻断）。UI 侧新增 `src/data/freshness.ts`：从各文件导出的元数据汇总为 `DATA_FRESHNESS` 清单（ID/LEVEL/YEAR/CHECKED_AT/NOTE），供「数据依据」面板渲染 §3 三档角标——展示数据不参与计算的既有纪律不变（insights.ts:9）。

**迁移顺序建议**：①PE2/X1/T2/T3/T5 四项按 §2 新值改数（DE 近似段重推、csi300 补录走行情接口复算）；②四缺登记文件补 `@data-meta` 头并入 data-dictionary（35 项扩表）；③check:data 增组 J；④D7/D6/D8 占位项转「缺登记→待校准」专项清单移交数据研究员。
