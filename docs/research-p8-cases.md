## §0 年度行通用约定（六条算例共用；实现须钉死，不得两条算例两套口径）

1. **行号—年龄**：第 t 行覆盖年龄 [当前年龄+t−1 → 当前年龄+t)；行首年龄 = 当前年龄+t−1。养老金流入行 = 行首年龄 ≥ 起领年龄（30 岁起算时即第 31 行起）。桥接行数 = bridgeYears（pension.rs:203-205 同式）。
2. **递推（名义口径）**：`A_t = A_{t−1}×(1+r_t) + 流入_t − 流出_t`——与 run_monte_carlo（bridge.ts:371）、simulate_accumulation（accumulation.rs:280）、simulate_sequence（sequence.rs:135/144）同构。
3. **支出上行**：`流出_t = 基期×∏_{k=1..t}(1+π_k)`（「固定实际支出」语义，bridge.ts:382）；养老金为名义定额不起调（pension.rs:8-11 简化口径），自起领年进入现金流（FireCalc「未来收入流自起始年进入」先例，research-retirement-models §3）。
4. **精度**：全精度递推、行值 round2 展示（accumulation.rs:301 先例：递推链在舍入之前）；断言容差 ±0.01 元。
5. **耗尽**：任一年末 A_t ≤ 0 判耗尽（bridge.ts:374「≤ 0」口径），当年及以后记 0。
6. **财富自由判定**：`A_t ≥ 目标×∏_{k=1..t}(1+π_k)`（目标随通胀水涨，accumulation.rs:290-292 同式）；初始 t=0 即判定（accumulation.rs:260）。

## §1 算例①：提前退休未领养老金（30 岁停工 / 60 起领——两段年度行连续性）

**输入**（PENSION_DEFAULTS + targetRetireAge=30；defaults.ts:168-179）：当前年龄 30、起领 60、停工 30；月开销 2,990；健康预留 200,000（一次性，已含在期初资产内）；r=4.5%、π=2.0% 恒定；期初资产 = 两段真实总需 **1,706,225.60**（README.md:86 锚点：桥接 1,435,200.00 + 领取后 271,025.60）；horizon 60 行（30→90 岁）。

**手算（月养老金，pension.rs:232-255 公式）**：
- 基础 = (10,343 + 10,343×0.6)÷2×30÷100 = 16,548.8÷2×0.3 = 8,274.4×0.3 = **2,482.32**；
- 账户 = 50,000÷139 = 359.7122… → **359.71**；月养老金 = 2,482.32+359.71 = **2,842.03**；年额 = 2,842.03×12 = **34,104.36**。

**手算（桥接段闭式）**：`A_t = A_0×1.045^t − 35,880×S_t`，其中 `S_t = Σ_{k=1..t}1.02^k×1.045^{t−k} = 1.045^t·q(1−q^t)/(1−q)`，q = 1.02/1.045。
- A_1 = 1,706,225.60×1.045 − 35,880×1.02 = 1,783,005.752 − 36,597.60 = **1,746,408.15**；
- 增长永续下限（growing perpetuity）：PV = 36,597.60÷(0.045−0.02) = **1,463,904** < A_0 → 桥接段永不击穿；
- A_30 = 1,706,225.60×1.045³⁰ − 35,880×S₃₀ = **3,559,230.95**（闭式 = 逐年递推，双路一致）。

**逐年期望（抽样行；全精度递推后 round2）**：

| 行 t | 行首年龄 | 期初 | 支出 35,880×1.02^t | 流入 | 期末 |
|---|---|---|---|---|---|
| 1 | 30 | 1,706,225.60 | 36,597.60 | 0 | 1,746,408.15 |
| 2 | 31 | 1,746,408.15 | 37,329.55 | 0 | 1,787,666.97 |
| 30 | 59 | 3,468,155.60 | 64,991.65 | 0 | **3,559,230.95**（桥接末行） |
| 31 | 60 | 3,559,230.95 | 66,291.49 | **34,104.36** | **3,687,209.22**（养老金首行） |
| 32 | 61 | 3,687,209.22 | 67,617.32 | 34,104.36 | 3,819,620.68 |
| 60 | 89 | 9,920,080.50 | 117,723.38 | 34,104.36 | **10,282,865.09** |

第 31 行手算复核：3,559,230.95×1.045 − 66,291.49 + 34,104.36 = 3,719,396.343 − 66,291.49 + 34,104.36 = 3,687,209.21（与全精度递推 3,687,209.22 差 0.01 元 = 舍入容差内，§0.4 口径）。终值 A_60 闭式复核：`A_0×1.045⁶⁰ − 35,880×Σ_{k=1..60}1.02^k·1.045^{60−k} + 34,104.36×(1.045³⁰−1)/0.045` = 10,282,865.09（与递推一致）。

**断言口径**：① 桥接行数恰 = 30 = estimate_pension(targetRetireAge=30).bridgeYears（60 − max(30,30)）；② 跨段连续：第 30 行期末 = 第 31 行期初，无重置、无一次性预留二次计入（修订轮二 R5 归属）；③ 第 31 行流入恰 = 34,104.36，第 1–30 行流入 = 0；④ 全 60 行 A_t > 0 且逐年增量 ≥ 40,182.55（本会话全表复核）；⑤ A_60 = 10,282,865.09 ± 0.01。

## §2 算例②：达标后暴跌（确定性序列：达标次年 −40%，年度行手算）

## §3 算例③：连续低回报（名义 1% < 通胀 3%——实际负增长下积累年限）

**输入**（ACCUMULATION_DEFAULTS 确定性化）：currentAssets 500,000、年储蓄 60,120×1.03^t（自第 1 年含当年通胀，accumulation.rs:279-280）、目标 1,635,200×1.03^t、r = +1% 恒定 < π = +3% 恒定；实际回报 = 1.01/1.03 − 1 = **−1.9417%/年**。

**手算（实口径闭式）**：`R_t = A_t/1.03^t = R_{t−1}×(1.01/1.03) + 60,120`，稳态 `R* = 60,120/(1−1.01/1.03) = 60,120×1.03/0.02 = 3,096,180`；
`R_t = 3,096,180 − 2,596,180×(1.01/1.03)^t`（R_0 = 500,000）。R* > 实目标 1,635,200 → 终将触达：
- R_29 = 3,096,180 − 2,596,180×0.980583²⁹ = **1,625,984.38** < 1,635,200；
- R_30 = **1,654,531.87** ≥ 1,635,200 → **首触第 30 行**（实口径富余 19,331.87）。

**逐年期望（实口径 R_t = A_t/1.03^t；名义行 A_t = R_t×1.03^t）**：

| 行 | 名义期末 A_t | 实口径 R_t | 实口径目标 1,635,200×1.03^t | 判定 |
|---|---|---|---|---|
| 1 | 566,923.60 | 550,411.26 | 1,684,256.00 | 未达标 |
| 10 | 1,293,209.15 | 962,269.06 | 2,197,572.06 | 未达标 |
| 20 | 2,424,212.50 | 1,342,227.69 | 2,953,353.09 | 未达标 |
| 29 | 3,831,738.71 | 1,625,984.38 | 3,853,455.92 | 未达标（差 9,215.62） |
| 30 | 4,015,983.12 | **1,654,531.87** | 3,969,059.59 | **首触（30 年）** |

**变体 B（实资产负增长本体）**：储蓄 0（月收入=月支出，合法输入）：R_t = 500,000×(1.01/1.03)^t 单调衰减——R_1 = 490,291.26、R_10 = 410,971.30、R_20 = 337,794.82；名义资产仍增长（A_10 = 500,000×1.01¹⁰ = 552,320.38）但目标名义值涨得更快（2,197,572.06）→ **永不触达**。

**断言口径**：① 首达年限 = 30（两路推导一致：名义递推与实口径闭式）；② 年度行名义值与实口径换算逐行自洽（A_t = R_t×1.03^t，±0.01）；③ 变体 B 永不触达 → 首达年限五个分位全部 = −1、neverReachedShare = 1.000000（accumulation.rs:378-379 契约）；④ 引擎对「名义回报均值 < 通胀均值」**不得报错**（accumulation.rs:195-196 仅校验 σ>0 与有界性；负均值合法，check_pct_signed 允许负值）；⑤ 实际回报 −1.9417%/年须在行级可复算（行 t 回报样本 0.01 − 通胀样本 0.03）。

## §4 算例④：通胀超回报（实际回报 ≤ 0——明确口径，禁除零/负乘数错误）

**输入**（BASELINE_DEFAULTS 变体）：回报 2.0%、通胀 2.0%（实际 = 0）；变体 B：回报 1.0%、通胀 3.0%（实际 = −2%）。

**手算（乘数口径边界）**：480 乘数 = 12÷实际回报小数。实际 = 0 → 12÷0 无定义（**不得输出 Infinity/NaN**）；实际 = −2% → 12÷(−0.02) = **−600**（负乘数无物理意义，**不得输出负值**）。既有契约（bridge.ts:103-104/116-117）：实际 ≤ 0 → error「通胀率需低于名义回报率」非空、multiplier = 0、criticalValue = 0、realReturnPct 照实回显、monthlyExpense 回显。费雪精确口径同界（bridge.ts:82-85）：实际 ≤ 0 → multiplierExact = 0。

**手算（行口径 r = i = 2%：实际零增长下的支取退化为线性实耗减）**：期初 1,435,200（= 2,990×480 桥接备资）、支出 35,880×1.02^t。实口径 `R_t = A_t/1.02^t = 1,435,200 − 35,880×t`（每行实减恒 35,880，回报恰抵通胀）：
- 第 1 行：A_1 = 1,435,200×1.02 − 36,597.60 = 1,463,904 − 36,597.60 = **1,427,306.40**（实口径 1,399,320.00）；
- 第 39 行：实口径 = 1,435,200 − 35,880×39 = **35,880.00**（恰剩一年实支出，A_39 = 35,880×1.02³⁹ = 77,671.04）；
- 第 40 行：实口径 = 1,435,200 − 35,880×40 = **0.00**（A_40 = 0.00，逐字节精确零）→ 按 §0.5「≤ 0 判耗尽」**恰第 40 行耗尽 = 480 个月 ÷ 12 = 40 年**（480 乘数的月数语义在 r=i 下退化为精确年数——教学口径边界闭环）；
- 第 41 行（若不终止）将出现 −35,880 实口径（A_41 = −80,808.95 名义）→ 引擎必须终止于第 40 行。

**积累侧（r = i = 2%）**：实口径 `R_t = 500,000 + 60,120×t`（回报恰保实际购买力，储蓄全数积累）：R_18 = 1,582,160 < 目标实 1,635,200；R_19 = **1,642,280** ≥ → **首触第 19 行**。

**断言口径**：① 实际 = 0 与实际 < 0 两变体均输出非空中文 error + multiplier/criticalValue = 0 + 输入回显字段照实（与 baseline/pension 同形状，pension.rs:209-225 同分支先例）——**不得**输出 Infinity、NaN、负乘数，**不得 panic**（bridge.ts:17 约定）；② 行口径 r=i 全程可递推、无除零路径；③ 支取序列第 40 行期末 = 0.00（±0.005）且 depletedYear = 40、第 39 行 = 77,671.04；④ 积累序列首触 = 19；⑤ UI/口径注须明示「r=i 时 480 乘数不可用、支取退化为 40 年线性实耗」——引擎输出明确口径而非静默错误值。

## §5 算例⑤：长寿命（60 年周期行数边界与性能预算）

**输入**：与算例①同参（30 岁→90 岁 = 60 行）；变体：无养老金单段支取（期初 1,435,200、支出 35,880×1.02^t、r=4.5%）。**手算（实口径）**：`R_t = R_{t−1}×(1.045/1.02) − 35,880`，实增长因子 1.024510 > 1 → 稳态 R* = 35,880/0.024510 = 1,463,904 为**不稳定**平衡点；R_0 = 1,435,200 < R* → 实口径单调缓降：`R_t = 1,463,904 − 28,704×1.024510^t`（R_60 = 1,463,904 − 28,704×1.024510⁶⁰ = **1,341,185.64** > 0）；理论耗尽点 1.024510^t > 51.00 → t > 162.4 年 → **60 行内不耗尽**。终值 A_60 = R_60×1.02⁶⁰ = **4,400,471.38**（递推 = 闭式双路一致）。

**行数边界**：60 行 = 30 岁人群到 90 岁的整寿命覆盖；既有上限参照——Rust 侧 MAX_YEARS = 200（accumulation.rs:65、montecarlo.rs 同值）、UI 侧 LIMITS.simYears max = 100（defaults.ts:60「同时控制图表规模」）→ 60 行在界内、且为**图表规模压力的合理代理上界**（P8 行数上限若取 100，60 行为其 60%）。断言：rows.length 恰 = 60，行号 1..60 无缺行、无重复，末行行首年龄 = 89。

**性能预算（建议门禁；本会话未实测，P8 实施时以计时脚本验收）**：确定性 60 行计划 **≤ 50 ms**（release 构建、单次同步调用，交互帧量级）；随机模式 60 年 × 5,000 路径 **≤ 2 s**（既有默认 40 年×5,000 路径×2 样本 = 40 万样本已交互可用，60 年为其 1.5 倍线性量级）；内存 O(rows×paths)——50 条 samplePaths×60 行 = 3,000 浮点值（accumulation.rs:46-48 固定 50 条口径不变）。

**断言口径**：① rows.length = 60 且首末行年龄 30/89 落位正确；② 确定性终值 = 10,282,865.09（含养老金）/ 4,400,471.38（无养老金变体，实口径 1,341,185.64 单调缓降、60 行内不耗尽），闭式与递推双路一致（±0.01）；③ 性能门禁达标（计时脚本实测值写入验收记录）；④ 60 行 × 50 条样本路径内存占用 = 3,000 值，无 OOM/截断。

## §6 算例⑥：同资料双口径一致性（引擎年度行 ↔ accumulation 双指标互证，同 seed 字节兼容）

**输入**（ACCUMULATION_DEFAULTS 原样，defaults.ts:183-198）：currentAssets 500,000、月收入 8,000、月支出 2,990、目标 1,635,200、4.5%±12%、2%±1%、years 40、paths 5,000、**seed 42**；变体 sustainYears = 10。

**同 seed 字节兼容引用（抽样流口径，实现级锁定）**：P8 引擎若消费同一随机流，必须沿用既有抽样序——路径外层、年份内层、每年先名义回报后通胀（accumulation.rs:5-8；bridge.ts:429-431 可复现性铁律）；pass1 样本数与顺序与 sustainYears 无条件解耦（三不变，accumulation.rs:39-45）；支取段派生种子 = `seed ^ ((p+1)×0x9E37_79B9_7F4A_7C15)`（accumulation.rs:336-338）。**断言：同 seed 42 同输入下，P8 年度行与 simulate_accumulation.samplePaths 对应行逐字节相等（含 round2 行舍入，accumulation.rs:301），fiProbability/yearsMedian/sustainedProbability 三值与既有输出逐字节一致。**（此为引擎-引擎互证断言；本清单不提供 seed 42 的随机样本数值真值——ChaCha 流不可手算，能锁定的是下列**结构恒等式**。）

**手算小例（假设样本 r=[+10%, −5%]、π=[+2%, +2%]，非 seed 42 真值；演示三口径同一性）**：
设目标 500,000、currentAssets 500,000 → t=0 即首触（accumulation.rs:260）：快照 A* = 500,000、cumInfl* = 1。
- 积累行：A_1 = 500,000×1.10 + 60,120×1.02 = 550,000 + 61,322.40 = **611,322.40**；A_2 = 611,322.40×0.95 + 60,120×1.02² = 580,756.28 + 62,548.848 = **643,305.13**；
- 双指标 pass1：首达年限 = 0（由行值回推：t=0 判定成立）→ 与输出 yearsMedian 一致；
- 支取行（pass2，N=2）：spend 基流 = 12×2,990×1 = 35,880；k=1：spend = 35,880×1.02 = 36,597.60，S_1 = 500,000×1.10 − 36,597.60 = **513,402.40** > 0；k=2：spend = 36,597.60×1.02 = 37,329.55，S_2 = 513,402.40×0.95 − 37,329.55 = **450,402.73** > 0 → 存续，sustainedProbability 计 1/paths；
- 支取基流公式 `12×monthlyExpense×cumInfl*`（accumulation.rs:341）与年度行支出口径（§0.3）在同一输入下逐值一致——互证点：**支取段第 1 年支出 = 积累段末年支出口径的通胀接续，无跳变**。

**断言口径**：① 同 seed 同输入：P8 行值 == samplePaths 行值（逐字节）；② 行派生首达年 = 输出年限分位（type-7、两位小数）；③ pass2 支出序列 = 年度行支出口径在同一通胀路径下的自然延拓（首年即含首个支取年通胀样本，accumulation.rs:344-355 与 §0.3 同语义）；④ sustainYears 增删不改既有字段（三不变，锁定测试 accumulation_sustained_invariant_same_seed 可侦测）；⑤ 随机样本数值本身**不可**以任何实现输出作为本清单真值。

## §7 边界结论（三条）

1. **两段时间口径可收敛为单一行模型**：养老金桥接（算例①）不必特判——把养老金作为「起领年进入现金流的名义定额流入」（§0.3）后，桥接段/领取后两段在同一条递推上无缝拼接（第 30→31 行连续性 + bridgeYears 行数对表即证）；一次性预留归属期初资产单次计入，480 乘数备资在 r=4.5%/π=2% 下按增长永续口径（下限 1,463,904）恰为**偏保守**（README:86 的 1,706,225.60 留有 24.2 万冗余），与 p7 已登记取舍方向一致。
2. **实际回报 ≤ 0 是「乘数族」输出与「行族」输出的分水岭**：乘数族（480/费雪/反向估算）必须走契约错误分支（0 + 中文 error，禁 Infinity/负乘数/panic）；行族（年度行）在 r=i 下数学上完全良态——支取退化为「40 年线性实耗」（480 月数语义闭环）、积累退化为「储蓄定速实际积累」——引擎须同时给出两族各自明确口径，不得以同一错误静默吞掉可算的行（算例④）。
3. **首触 ≠ 持续，达标后暴跌边界须靠「行序列 + 双指标」联合呈现**：算例②首触第 11 行、暴跌后第 17 行差 2,476.95 未复达、第 18 行复触——首达年限指标对暴跌不敏感（仍是 11），只有年度行暴露「达标后 −597,303.27 回撤」；而「存续」判定（≤0 口径）在资产恒正的本路径上对任意 N 恒成立、对跌破目标无感——**fiProbability、sustainedProbability、年度行三者缺一都会误报**，P8 引擎必须三者同源（同一行序列派生，算例⑥恒等式）且口径注明示。
